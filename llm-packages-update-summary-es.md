#### R packages
- **13** new packages! including:
  - Orquestación de agentes LLM para flujos con checkpoints y revisión humana (`puppeteeR`)
  - Skills y archivos de instrucciones para agentes orientados a codificación de paquetes R (`pkgskills`)
  - Análisis de R code vía AST para gestionar contexto y dependencias (`saber`)
  - Resúmenes y análisis textuales para resultados de `profvis` en workflows de terminal (`debrief`)
  - Detección y sugerencias de correcciones de inconsistencias semánticas en data frames con LLM (`llmclean`)
  - Interfaz minimalista de chat LLM con integración multi-proveedor y streaming (`llm.api`)
  - Integración entre R y Goose AI para automatización y gestión de proyectos de ciencia de datos (`gooseR🦆`)
  - Filtrado de títulos/resúmenes para revisiones sistemáticas y herramientas de evaluación de calidad (`AIscreenR`)
  - Asistente multi-proveedor y consciente del contexto de RStudio (incl. git) con énfasis en seguridad y aprobación (`ravel`)
  - SDK de desarrollo de software de IA para R con salidas estructuradas, tool calling y orquestación multi-agente (`aisdk`)
  - Interfaz ligera para la API de OpenAI ChatGPT desde R (`gptr`)
  - Wrappers para GPT en flujos de trabajo de R (tests, traducción, refactorización, validación de R, etc.) (`TheOpenAIR`)
  - Codificación cualitativa asistida por IA para datasets grandes con audit trail y validaciones (`quallmer`)
